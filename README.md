# ⚡ EKT.KZ — AI Ассистент (ГК Электрокомплект)

AI-консультант для интернет-магазина электрооборудования **ekt.kz** на Go + OpenAI GPT-4o-mini.

## 🚀 Быстрый старт

```bash
git clone https://github.com/BAITC-Hacks/hack-400d70df-donerka-house
cd hack-400d70df-donerka-house
go mod tidy

# С AI (нужен OpenAI API Key)
OPENAI_API_KEY=sk-... go run main.go

# С официальным API EKT (Basic Auth; секреты задаются только на сервере)
EKT_API_BASE_URL=https://ekt.kz/api \
EKT_API_USERNAME=apiuser \
EKT_API_PASSWORD=... \
OPENAI_API_KEY=sk-... go run main.go

# Демо-режим (без ключа)
go run main.go
```

Открыть: **http://localhost:8080**

## 🌐 API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `GET` | `/` | Главная страница |
| `GET` | `/api/catalog` | Все товары из JSON файлов |
| `POST` | `/api/chat` | Поиск, наличие, характеристики, аналоги, условия покупки и подтверждённое добавление в корзину |
| `GET` | `/api/auth` | Получить текущий статус локального аккаунта |
| `POST` | `/api/auth` | Регистрация или вход: `{ "action": "register", "email": "...", "name": "...", "password": "..." }` |
| `DELETE` | `/api/auth` | Выйти из локального аккаунта |
| `GET` | `/api/cart` | Получить актуальную корзину аккаунта или браузерной сессии |
| `POST` | `/api/cart` | Прямое добавление запрещено: изменение корзины выполняется только после подтверждения через чат |
| `DELETE` | `/api/cart?article=200300285_` | Удалить товар; без `article` очистить корзину |
| `GET` | `/health` | Статус сервера |

### Пример чата:
```bash
curl -X POST http://localhost:8080/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Нужен автоматический выключатель 160А, что есть?"}'
```

### Пример корзины:
```bash
# Cookie из ответа сохраняет корзину текущего клиента
curl -c cookies.txt -b cookies.txt http://localhost:8080/api/cart
curl -c cookies.txt -b cookies.txt -X POST http://localhost:8080/api/cart \
  -H "Content-Type: application/json" \
  -d '{"article":"200300285_","quantity":1}'
curl -c cookies.txt -b cookies.txt -X DELETE \
  'http://localhost:8080/api/cart?article=200300285_'
```

## 👤 Аккаунт и корзина

На localhost доступна регистрация и вход через кнопку «Войти». Пароли сохраняются только как salted hash в `data/accounts.json`, а сессия — в HttpOnly-cookie. Если пользователь добавил товары как гость, после входа гостевая корзина автоматически переносится в аккаунт. AI, карточки товаров и `/api/cart` используют одну и ту же корзину аккаунта.

Файл аккаунтов не коммитится в Git и сохраняется Docker Compose volume `./data:/app/data`. Для production следует заменить JSON-хранилище и in-memory корзину на PostgreSQL/Redis с серверной защитой сессий.

Это локальный аккаунт приложения. Сервисные credentials Basic Auth для `/api/products` не являются логином покупателя EKT. Для открытия настоящего кабинета EKT в модальном окне оставлена отдельная ссылка `https://ekt.kz/personal/`; синхронизация с серверной корзиной EKT требует официального customer-auth/cart API от EKT.

## 🛒 Корзина и AI-добавление

Гостевая корзина привязана к HttpOnly-cookie `ekt_session`, а корзина аккаунта — к серверной сессии пользователя.

Добавление работает в два шага:

1. Клиент выбирает товар и количество, например `Добавь 2 шт 200300285_`.
2. Ассистент показывает выбранный товар и просит отдельное подтверждение **«да, добавь»**.
3. Только после этого сервер изменяет корзину.

Фразы `хочу купить`, `беру`, `дай 5 шт`, `добавь 5 шт` и простое `да` сами по себе корзину не меняют. Прямой `POST /api/cart` для добавления заблокирован, чтобы нельзя было обойти подтверждение.

Перед подтверждённым добавлением сервер проверяет известный региональный или общий остаток EKT. Если запрошенное количество превышает остаток, корзина не меняется и ассистент сообщает доступный лимит.

После успешного добавления API возвращает `cart_url: "/#cart"`. Эта ссылка открывает актуальную корзину той же браузерной/аккаунт-сессии.

## 🔎 Live-каталог EKT

Перед ответом ассистент ищет товары на публичной странице `https://nursultan.ekt.kz/catalog/?q=...` и загружает страницы найденных товаров, чтобы получить описание, назначение и характеристики. JSON API EKT требует отдельную авторизацию, поэтому приложение не подменяет её OpenAI-ключом и не отправляет его на EKT. Региональный адрес можно изменить через `EKT_CATALOG_URL`.

При заданных `EKT_API_USERNAME` и `EKT_API_PASSWORD` сервер использует официальный API EKT с Basic Auth: загружает страницы `/api/products` и получает детали выбранных товаров через `/api/products/detail?id=...`. Эти секреты передаются только серверу через `.env`/Docker Compose и не хранятся в репозитории. Если API временно недоступен или переменные не заданы, остаётся безопасный fallback на локальный снимок и публичные HTML-страницы.

Из карточки EKT читается актуальный статус наличия текущего региона: `В наличии` или `Под заказ`. При доступном API ассистент дополнительно получает общий остаток и разбивку по складам. Поэтому он может ответить, например: «В наличии в Астане, до 8 шт.; общий остаток по EKT — 23 шт.» или «Под заказ».

Ассистент сохраняет короткий контекст сессии: после показа карточек можно спросить «для чего нужен этот товар?» или написать «дай 5 шт», и он понимает, что речь идёт о последнем выбранном товаре. Для изменения корзины всё равно требуется отдельное подтверждение «да, добавь».

Для товара со статусом «Под заказ» или «Нет в наличии» ассистент подбирает доступные аналоги по названию и совпадающим техническим характеристикам и кратко объясняет выбор. Ссылки на сертификаты извлекаются из публичной карточки EKT или из детального ответа официального EKT API, если они присутствуют в исходных данных.

## ✅ Must Have — реализованные сценарии

1. **Наличие, характеристики и сертификаты:** статус, остатки, склады, описание, свойства и ссылки на сертификаты, когда они есть в EKT.
2. **Аналоги:** при отсутствии товара возвращается минимум один релевантный доступный аналог, если такой есть в каталоге, с кратким обоснованием.
3. **Условия покупки:** ассистент отвечает про оплату, доставку и минимальную партию. Для прототипа минимальная партия — **1 шт.**, если для позиции не указано иное.
4. **Подтверждение корзины:** до отдельного сообщения **«да, добавь»** корзина не меняется; запрошенное количество проверяется по известному остатку.
5. **Ссылка на корзину:** после добавления возвращается `/#cart`, ведущая на актуальное состояние текущей session/account-корзины.

Проверка:

```bash
go test ./...
go run main.go
```

Ручной сценарий:

```text
дай 200300278
дай 5 шт
# корзина не меняется
да, добавь
# товар добавлен и появляется ссылка на актуальную корзину
```
