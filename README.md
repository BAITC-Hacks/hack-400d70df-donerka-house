# ⚡ EKT.KZ — AI Ассистент (ГК Электрокомплект)

AI-консультант для интернет-магазина электрооборудования **ekt.kz** на Go + OpenAI GPT-4o-mini.

## 🚀 Быстрый старт

```bash
git clone https://github.com/BAITC-Hacks/hack-400d70df-donerka-house
cd hack-400d70df-donerka-house
go mod tidy

# С AI (нужен OpenAI API Key)
OPENAI_API_KEY=sk-... go run main.go

# С официальным API EKT (Basic Auth; секреты задаются только на сервере)
EKT_API_BASE_URL=https://ekt.kz/api \
EKT_API_USERNAME=apiuser \
EKT_API_PASSWORD=... \
OPENAI_API_KEY=sk-... go run main.go

# Демо-режим (без ключа)
go run main.go
```

Открыть: **http://localhost:8080**

## 🌐 API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| `GET` | `/` | Главная страница |
| `GET` | `/api/catalog` | Все товары из JSON файлов |
| `POST` | `/api/chat` | Вопрос AI-ассистенту; поиск, аналоги, условия покупки и подтверждённое добавление в корзину |
| `GET` | `/api/cart` | Получить актуальную корзину текущей браузерной сессии |
| `POST` | `/api/cart` | Прямое добавление запрещено: товар добавляется только после подтверждения через чат |
| `DELETE` | `/api/cart?article=200300285_` | Удалить товар; без `article` очистить корзину |
| `GET` | `/health` | Статус сервера |

### Пример чата:
```bash
curl -X POST http://localhost:8080/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "Нужен автоматический выключатель 160А, что есть?"}'
```

### Пример корзины:
```bash
# Cookie из ответа сохраняет корзину текущего клиента
curl -c cookies.txt -b cookies.txt http://localhost:8080/api/cart
curl -c cookies.txt -b cookies.txt -X POST http://localhost:8080/api/cart \
  -H "Content-Type: application/json" \
  -d '{"article":"200300285_","quantity":1}'
curl -c cookies.txt -b cookies.txt -X DELETE \
  'http://localhost:8080/api/cart?article=200300285_'
```

## 🛒 Корзина и AI-добавление

Корзина привязана к HttpOnly-cookie `ekt_session` и хранится в памяти процесса. Это подходит для прототипа и одного экземпляра приложения.

Добавление работает в два шага:
1. Клиент выбирает товар и количество, например: `Добавь 2 шт 200300285_`.
2. Ассистент показывает выбранный товар и просит отдельное подтверждение `да, добавь`.
3. Только после этого сервер меняет корзину.

Фразы `хочу купить`, `беру`, `дай 5 шт` и `добавь 5 шт` сами по себе корзину не меняют. Даже простое `да` не считается достаточным подтверждением. Прямой `POST /api/cart` для добавления заблокирован, чтобы нельзя было обойти подтверждение.

Перед добавлением сервер проверяет доступный остаток. Если клиент просит больше, чем опубликованный региональный или общий остаток EKT, корзина не меняется и ассистент сообщает допустимое количество.

После успешного добавления ответ содержит `cart_url: "/#cart"`. Ссылка открывает корзину этой же браузерной сессии, поэтому показывает её актуальное состояние.

## 🔎 Live-каталог EKT

Перед ответом ассистент ищет товары на публичной странице `https://nursultan.ekt.kz/catalog/?q=...` и загружает страницы найденных товаров, чтобы получить описание, назначение и характеристики. JSON API EKT требует отдельную авторизацию, поэтому приложение не подменяет её OpenAI-ключом и не отправляет его на EKT. Региональный адрес можно изменить через `EKT_CATALOG_URL`.

При заданных `EKT_API_USERNAME` и `EKT_API_PASSWORD` сервер использует официальный API EKT с Basic Auth: загружает страницы `/api/products` и получает детали выбранных товаров через `/api/products/detail?id=...`. Эти секреты передаются только серверу через `.env`/Docker Compose и не хранятся в репозитории. Если API временно недоступен или переменные не заданы, остаётся безопасный fallback на локальный снимок и публичные HTML-страницы.

Из карточки EKT читается актуальный статус наличия текущего региона: `В наличии` или `Под заказ`. При доступном API ассистент дополнительно получает общий остаток и разбивку по складам. Поэтому он может ответить, например: «В наличии в Астане, до 8 шт.; общий остаток по EKT — 23 шт.» или «Под заказ».

Ассистент сохраняет короткий контекст браузерной сессии: после показа карточек можно спросить «для чего нужен этот товар?» или написать «дай 5 шт», и он понимает, что речь идёт о последнем выбранном товаре. Для изменения корзины всё равно требуется отдельное подтверждение «да, добавь».

Если товар имеет статус «Под заказ» или «Нет в наличии», ассистент ищет релевантные аналоги по названию и совпадающим техническим характеристикам и кратко объясняет выбор. Ссылки на сертификаты извлекаются из публичной карточки EKT или из детального ответа официального API, если они присутствуют в данных.

## ✅ Must Have — реализованные сценарии

1. **Наличие, характеристики и сертификаты.** Live-каталог и официальный EKT API передают статус наличия, количество, склады, описание, технические свойства и ссылки на сертификаты, когда они есть в источнике.
2. **Аналоги.** Для товара без остатка/под заказ предлагаются доступные похожие позиции с кратким обоснованием по совпадающим характеристикам.
3. **Условия покупки.** Ассистент отвечает про оплату, доставку и минимальную партию. Для прототипа минимальная партия — **1 шт.**, если для товара не задано иное.
4. **Подтверждение корзины и остаток.** До отдельного сообщения **«да, добавь»** корзина не меняется; количество не может превышать известный остаток.
5. **Прямая ссылка на корзину.** После подтверждённого добавления API возвращает `/#cart`, которая открывает актуальную session-корзину.

Проверка:

```bash
go test ./...
go run main.go
```

Рекомендуемый ручной сценарий:

```text
дай 200300278
дай 5 шт
# корзина ещё не меняется
да, добавь
# товар добавлен, появляется ссылка на актуальную корзину
```
